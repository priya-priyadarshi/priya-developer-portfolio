# Priya's Developer Portfolio

A responsive React + CSS portfolio built with Vite.

## Run locally

1. Install Node.js (LTS) from https://nodejs.org/ if you do not already have it.
2. Open Terminal in this folder.
3. Run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Customize before publishing

- In `src/main.jsx`, replace `your.email@example.com` with your real public contact email.
- Replace the GitHub and LinkedIn links with your actual profile URLs.
- In the `projects` array, add real GitHub/live demo URLs in each project's `link` field when available. Empty links intentionally show “In progress”.
- Keep only skills and project claims you can explain and demonstrate.
- Update project descriptions and add real project screenshots as you create them.

## Build for deployment

```bash
npm run build
npm run preview
```

The production output is created in `dist/`.
